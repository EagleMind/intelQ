# MOD-001 — DB Connection & Query Engine

## Scope (files this agent owns)

```
src-tauri/src/lib.rs                    ← pool management, schema cache, all Tauri commands
src-tauri/src/appdb.rs                  ← connections table schema + CRUD (shared with MOD-004)
src/services/api.ts                     ← typed Tauri IPC wrappers
src/store/DbContext.tsx                 ← React Context: connection state, schema, tables
src/components/ConnectionsManager.tsx   ← modal UI: CRUD saved connections, quick connect
src/types/api.ts                        ← TableColumn, QueryResult, etc. (shared contract)
```

## What This Module Does

Manages the lifecycle of a live database connection:
- Creates/destroys connection pools (sqlx, multi-DB: SQLite / PostgreSQL / MySQL)
- Caches the full schema on connect (one query, not N-per-table)
- Executes SQL queries, returns column-aligned rows (`Vec<Vec<Option<String>>>`)
- Provides schema text to other modules (LLM prompt, annotation panel)
- Exposes connection state via `DbContext` React context

## Key Files — What to Know Before Editing

### `lib.rs`
- `AppState` holds: `db_pool: RwLock<DatabasePool>`, `schema: RwLock<Option<SchemaCache>>`, `app_db: RwLock<SqlitePool>`
- `DatabasePool` is an enum: `Sqlite | Postgres | MySQL | None`. **Clone is cheap** (Arc-backed).
- Schema is cached on `connect_database`. Rebuilt only on `refresh_schema`.
- `state.pool()` snapshots the pool then releases the lock — never hold the lock during query execution.
- `validate_table_name()` enforces alphanumeric+underscore+dash only — always call before using table names in raw SQL.
- All Tauri commands return `Result<T, String>` — never panic, always map errors to string.
- New commands must be added to `invoke_handler![]` at the bottom of the file.

### `DbContext.tsx`
- `markConnected(name?, id?, dbType?)` — call after a successful connection. Triggers schema load. Sets `connectionId` and `connectionDbType` on `status`.
- `status.connectionId` is consumed by `AnnotationContext` (MOD-002) to auto-load annotations.
- `disconnect()` resets status (including connectionId/dbType).
- `readOnlyLock` persisted via `sync.setSetting('readOnlyLock', ...)`.

### `ConnectionsManager.tsx`
- On connect success: calls `markConnected(record.name, record.id, record.db_type)` — **must pass all three args** or annotation loading breaks.
- Password stored in OS keychain under `conn_{id}_password` — never in SQLite.
- One-time migration from localStorage on first load.

### `api.ts`
- All functions call `safeInvoke<T>(command, args)` from `utils/tauri.ts`.
- Adding a new backend command: add the typed wrapper here first.

## Public API (what other modules call)

```typescript
// DbContext
const { status, tables, schema, markConnected, disconnect, refreshSchema } = useDb();
status.connectionId      // used by MOD-002 to scope annotations
status.connectionDbType  // used by MOD-002 for native COMMENT SQL generation
schema                   // used by MOD-003 (LLM prompt) and MOD-002 (column parsing)
tables                   // used by MOD-002 and MOD-003

// api.ts
api.connect(args)
api.execute(sql)
api.getSchema()
api.getFilteredSchema(tables)
api.getTableData(table, limit, offset)
```

## Critical Constraints

- **Multi-database**: any change to query logic must handle all three arms of `DatabasePool` match.
- **Schema cache**: `get_schema` returns cached data — use `refresh_schema` if you need fresh data.
- **Column-aligned rows**: `QueryResult.rows` is `Vec<Vec<Option<String>>>`, NOT `Vec<HashMap<String, Value>>`. The frontend builds column index from `columns` array.
- **SQL safety**: `execute_query` does NOT validate SQL — the frontend `SQLSafetyAnalyzer` does. Backend trusts the caller.

## Contract

- `useDb()` returns `{ status, tables, schema, markConnected, disconnect, refreshSchema }` — consumed by every other module. @anchor src/store/DbContext.tsx
- `status.connectionId` is the live connection ID — MOD-002 reads this to scope annotations. @anchor src/store/DbContext.tsx
- `schema` is a plain-text schema string — MOD-003 injects it into the LLM prompt. @anchor src/store/DbContext.tsx
- All typed Tauri IPC wrappers live in `api.ts` — other modules call through these, not raw `safeInvoke`. @anchor src/services/api.ts
- New Tauri commands must be added to `invoke_handler![]` in `lib.rs`. @anchor src-tauri/src/lib.rs

## Invariants

- `markConnected(name, id, dbType)` requires all three arguments — omitting `id` or `dbType` silently breaks annotation auto-loading. @anchor src/components/ConnectionsManager.tsx
- `validate_table_name()` must be called before any table name is used in raw SQL — enforces alphanumeric+underscore+dash only. @anchor src-tauri/src/lib.rs
- All Tauri commands return `Result<T, String>` — never panic, never return a non-string error. @anchor src-tauri/src/lib.rs
- `DatabasePool` has four arms (Sqlite, Postgres, MySQL, None) — every match on the pool enum must handle all four. @anchor src-tauri/src/lib.rs

## Internal

- `state.pool()` snapshots the pool and releases the lock before use — never hold the read lock during query execution. @anchor src-tauri/src/lib.rs
- Schema is cached on connect and only rebuilt by `refresh_schema` — `get_schema` returns cached data. @anchor src-tauri/src/lib.rs
- `QueryResult.rows` is `Vec<Vec<Option<String>>>`, not a map — the frontend aligns columns by index. @anchor src/services/api.ts
