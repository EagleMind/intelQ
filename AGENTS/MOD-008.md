# MOD-008 — Onboarding Guide

## What This Module Does

Multi-step onboarding flow shown before the user enters the workspace:
1. Connect a database (calls `onOpenConnections()`)
2. Configure AI provider (uses `AiProviderForm` from MOD-003)
3. Enter workspace (calls `onEnter()`)

The component is a controlled accordion that tracks which step the user is on and prevents skipping. User can explore tables without AI, or wait until both DB and AI are configured.

## Contract

- `SetupGuide` component accepts `{ onOpenConnections: () => void, onEnter: () => void }` — MOD-007 passes these callbacks and renders the guide conditionally. @anchor src/components/SetupGuide.tsx
- Reads `useDb()` for connection state (`status.connected`, `status.connectionName`, `disconnect`). @anchor src/components/SetupGuide.tsx
- Reads `useAiSettings()` for AI readiness (`aiReady`, `provider`). @anchor src/components/SetupGuide.tsx
- Embeds `AiProviderForm` from MOD-003 for step 2. @anchor src/components/SetupGuide.tsx

## Invariants

- Step 2 is not auto-complete even with LM Studio default — user must explicitly save the form (`aiConfirmed` gate). @anchor src/components/SetupGuide.tsx
- Do not add new steps — this is intentionally three steps, matching the onboarding narrative. @anchor src/components/SetupGuide.tsx

## Internal

- `openOverride` state allows manual step toggling (UI affordance); current step auto-selects based on completion. @anchor src/components/SetupGuide.tsx
- Step 3 has two paths: "Enter workspace" (both done), "Explore without AI" (DB only). Do not add a third path. @anchor src/components/SetupGuide.tsx
- Uses lucide-react icons (`Database`, `Sparkles`, `MessageSquareText`, `Check`, `ChevronDown`, `ArrowRight`). @anchor src/components/SetupGuide.tsx
