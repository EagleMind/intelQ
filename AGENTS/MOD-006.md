# MOD-006 — UI Primitives & Theme

## Scope (files this agent owns)

```
src/index.css                         ← CSS custom properties, design tokens, utility classes
src/components/ui/button.tsx          ← shadcn/ui Button primitive
src/components/ui/dropdown-menu.tsx   ← shadcn/ui DropdownMenu primitive
src/components/theme-provider.tsx     ← ThemeProvider: system/light/dark with localStorage
src/components/theme-toggle.tsx       ← ThemeToggle button (sun/moon icon)
```

## What This Module Does

Provides the visual foundation for every component in the app:
- **CSS custom properties** for all colors, spacing, and radii — allows light/dark mode with zero component-level logic
- **Theme switching** via `ThemeProvider` (system, light, dark) — persisted to `localStorage` under `storageKey`
- **Primitive components** (Button, DropdownMenu) from [shadcn/ui](https://ui.shadcn.com/) — built on Radix UI + Tailwind
- **Utility classes** in `index.css` for modals, forms, connection cards, loading spinners, and status indicators

## CSS Custom Properties (Design Tokens)

These are defined in `src/index.css` and must be used by all components. **Never use raw hex colors in component code.**

### Light / Dark Mode

The `:root` block defines light-mode values. The `.dark` class (toggled by `ThemeProvider`) overrides them:

| Variable | Purpose |
|----------|---------|
| `--background` | Page background |
| `--foreground` | Primary text |
| `--card` | Card/panel background |
| `--card-foreground` | Text on cards |
| `--primary` | Brand accent (buttons, links, active states) |
| `--primary-foreground` | Text on primary-colored elements |
| `--secondary` | Secondary interactive elements |
| `--secondary-foreground` | Text on secondary elements |
| `--muted` | Disabled / subdued backgrounds |
| `--muted-foreground` | Subdued text |
| `--border` | Borders and dividers |
| `--destructive` | Error/danger states |
| `--success` | Success / connected indicator |
| `--warning` | Warning states |
| `--radius` | Default border radius |

## ThemeProvider / ThemeToggle

- `ThemeProvider` wraps the entire app in `App.tsx`
- Props: `defaultTheme: 'system' | 'light' | 'dark'`, `storageKey: string`
- Sets the `dark` class on `document.documentElement` based on system preference or explicit choice
- `ThemeToggle` renders a sun/moon icon button that cycles through themes

## shadcn/ui Primitives

- `Button` (`src/components/ui/button.tsx`): uses `class-variance-authority` for variant/size props
- `DropdownMenu` (`src/components/ui/dropdown-menu.tsx`): wraps Radix UI `DropdownMenu`
- To add more shadcn components: use `npx shadcn@latest add <component>` or manually copy following the same pattern

## Rules for All Agents

1. **Use CSS variables, not hex colors**. `text-primary` not `text-[#4f46e5]`.
2. **Use existing utility classes** from `index.css` before creating new ones.
3. **Dark mode is automatic** — any element using CSS variables is already dark-mode compatible; no `dark:` Tailwind variants needed for color.
4. **Tailwind** is configured with the `cn()` helper from `src/lib/utils.ts` for conditional class merging.
5. **Icons**: the app uses [lucide-react](https://lucide.dev/). Do not introduce a second icon library.
